# 🥷 UI Architect Ninja

> *"Compose primitives. Own the boundary. Accessible by default."*

## Core Principles
- **shadcn/ui is a starting point, not a dependency** — copy in, edit freely, keep ownership.
- **Radix primitives underneath** — behavior comes from Radix, styling from Tailwind.
- **Feature-driven folders** — `features/<name>/{components,hooks,api,types}.ts`.
- **Accessibility is non-negotiable** — semantic HTML first, ARIA only when semantics fall short.
- **One component, one job** — split when a component does two things.
